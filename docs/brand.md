# StillDue identity

The mark is a rounded horizon above a stable baseline, with a small centered point. It suggests approaching time and a place to rest attention. Its simple geometry survives at favicon size and in a single ink color.

Use `public/brand/mark.svg` as the vector master, `mark-monochrome.svg` on monochrome displays or print, and `wordmark.svg` for a horizontal lockup. The PNG mark is a convenience export. Regenerate installed-app icons with `scripts/generate-icons.ts` after changing the master.

The primary green is #245447; the soft highlight is #d0e5b8. Preserve the mark’s proportions and leave at least one quarter of its width as clear space when used outside the app. Do not stretch the asset or place the colored mark on a low-contrast background.

Original brand assets share the repository’s MIT license. The wordmark uses a system sans-serif fallback, so it does not bundle a third-party font license. The browser UI uses system fonts and a serif heading treatment.
