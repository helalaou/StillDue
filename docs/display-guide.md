# A board for your desk

A desk display makes a deadline an environmental cue instead of something that must be actively recalled or found inside another app. The useful part is its ordinary presence: a glance can answer what is next and how much time remains, then let attention return to the work. Keep the board calm enough that it remains worth looking at. Show a small number of active commitments, use Focus for the immediate horizon, and move completed work out of view.

An older or inexpensive tablet is enough. Put it on a stand, open StillDue in the browser, add it to the home screen when supported, and keep it connected to power using the device maker’s battery-care guidance. Edit deadlines from another device; the signed-in display receives the same workspace updates. A spare computer monitor, browser-capable e-reader, or e-ink monitor connected to a computer can serve the same purpose.

Open Display mode from the sidebar after signing in. Choose one board or all active deadlines. Fullscreen removes browser chrome where supported. Lock hides editing/navigation controls to reduce accidental taps; it is a convenience, not an account security boundary.

Choose a column count and text size in Settings. The grid reduces columns on smaller screens. If there are more than two rows of cards, display mode provides pages so content stays readable. It does not automatically rotate the page while someone is reading.

The e-ink preset is specific to the device. It uses black and white, clear borders, no animations, and five-minute refreshes to reduce unnecessary redraws. The display shows its last successful sync time and warns when offline. It can keep counting from cached timestamps, but source edits need a connection.

Keep-awake is optional and only applies while the page is visible. Browsers may refuse it because of battery or platform restrictions. Fullscreen, app installation, and wake lock are not available on every e-reader. Test the actual device before leaving it unattended.

Use a browser-capable tablet, e-ink monitor attached to a computer, or an e-ink device with a compatible browser. A device that only accepts uploaded images needs a future image-feed adapter.
